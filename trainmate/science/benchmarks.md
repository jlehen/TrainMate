BENCHMARK (FITNESS TEST) GUIDELINES
===================================

AUTHORITY: MEASUREMENT. This file defines what a threshold anchor is, when a
test result can be trusted, and when a measured difference is real. Which blocks
need which anchors is a plan document's decision — except for the rules marked
FLOOR, which are properties of the measurement and never yield.

A benchmark workout is a standardized, repeatable maximal or threshold effort
whose result establishes the athlete's THRESHOLD ANCHOR. All training zones and
session targets are derived as a percentage of that anchor. The concept is
sport-generic:

   benchmark workout  ->  threshold anchor  ->  training zones / targets


1. WHEN TO RE-BENCHMARK
-----------------------
The default is NOT to test. Re-anchor on EVIDENCE that the anchor is stale,
never on the calendar or on a position in the block structure. A test costs a
quality session and a day of freshness. Run one when:
   - Sessions systematically decouple from their target zones — planned efforts
     consistently too easy or too hard, across several sessions rather than one
     bad day. This is the primary trigger: direct evidence the anchor is wrong.
   - Returning from a detraining gap (illness, injury layoff, travel block),
     where the anchor is stale and probably too high.
   - Entering a block whose targets DEPEND on that anchor, with nothing recent
     establishing it. Not every transition qualifies — a block of all-out
     unpaced work needs no threshold anchor.
   - The anchor has never been measured. A seeded or self-reported value is a
     guess, not a measurement; the first real test is worth running early.
Absent a trigger, do not test. A block boundary is not a trigger.

MINIMUM INTERVAL — FLOOR: never test the same anchor twice within 4 weeks.
Below that the difference is measurement noise, so the test buys no information
and costs real fatigue. This holds however the plan is structured — short
blocks do not get a test at every boundary.

TYPICAL CADENCE: 8-12 weeks between tests of the same anchor — a handful per
year. Testing every 4 weeks clears the floor and is still the classic error:
it converts training into testing and invites acting on noise (§3).

DO NOT TEST COMPROMISED — FLOOR: a test run ill, sleep-deprived, or on
suppressed recovery metrics yields a wrong anchor, not a low reading of today's
fitness. Postpone it. Do not test in the run-in to a goal event either: the
test competes with the effort it serves, and the taper lifts performance past
the tested value before it is ever used.

TEST FRESH. A recovery/deload week's END is the single best slot — fatigue has
dissipated and the session displaced was going to be easy anyway. A race TAPER
is the opposite case: a maximal effort is exactly the stress the taper exists
to remove.


2. BENCHMARK PROTOCOL AND ANCHOR BY SPORT
-----------------------------------------
   Cycling:
     - Protocol: 20-min maximal steady effort (FTP = avg power x 0.95), or a
       ramp test.
     - Anchor: FTP (power). Zones = % of FTP.

   Running:
     - Protocol: 30-min time trial (avg pace/HR of last 20 min ~= threshold),
       Critical Speed test, or a 5k time trial.
     - Anchor: Threshold pace / Critical Speed. Zones = % of threshold pace
       (or pace bands).

   Swimming:
     - Protocol: Critical Swim Speed test (e.g. 400m + 200m time trials).
     - Anchor: CSS (pace per 100m). Zones = offsets from CSS pace.

   Rowing:
     - Protocol: 2k test, or 30-min test.
     - Anchor: Threshold pace/power. Zones = % of threshold.

   Strength:
     - Protocol: 1RM test, or estimated 1RM (e1RM) from a reps-to-near-failure
       or velocity-based set (safer, lower fatigue).
     - Anchor: 1RM (load). Working loads = % of 1RM.

   General aerobic (fallback):
     - Protocol: Cooper test / maximal aerobic speed or power test.
     - Anchor: MAS / MAP / VO2max proxy.

PROTOCOL IS PART OF THE MEASUREMENT. The protocols above are alternative ways
to ESTABLISH an anchor, not interchangeable ways to measure the same one — a
ramp test and a 20-minute test systematically disagree, in a rider-dependent
direction. Pick one protocol per anchor and keep it; venue and conditions
(indoor vs outdoor, trainer, course) are part of the protocol.


3. READING A RESULT
-------------------
MINIMUM MEANINGFUL CHANGE — FLOOR: treat a new value as a CHANGE only if it
clears roughly 3-5% (cycling FTP: ~8-10 W) AND came from the same protocol and
conditions. Below the band it is another reading of the same anchor — do not
recompute zones from it. A protocol or venue switch starts a new series: report
the value as a fresh baseline, never as a gain or a loss.

When a change is real, the new value becomes the single source of truth and
every dependent zone and target recomputes from it.

TREND, NOT POINTS. A rising anchor across tests confirms overload is working; a
stalled or falling one across blocks signals plateau or under-recovery. One
test is a point, not a trend — and only same-protocol values form a series.


4. COACHING DIRECTIVES
----------------------
   - Prescribe from the anchor you have: old but uncontradicted beats fresh but
     compromised.
   - Never let a test displace the training it serves: if fitting it in means
     cutting the block's key session, it is not due.
